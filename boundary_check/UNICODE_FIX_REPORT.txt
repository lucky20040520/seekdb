完成内容

1. 反引号标识符使用完整 Unicode 小写转换，统一表名、列名、索引名和别名。
   除 Ä/ä 等单字符映射外，也覆盖 İ -> i + U+0307 和希腊 Σ 的 Final_Sigma
   上下文规则。与 Python lower() 一致，不使用 casefold 或 NFC/NFKC；ß/ss、
   é/e + U+0301 等不同名字仍然可以共存。Unicode 标识符继续使用反引号语法。

2. SQL 空白与 Python str.isspace() 一致，共 29 个字符；SQL 数字与 Python
   re 的 Unicode Nd 范围一致，共 680 个十进制数字。只在数字 token 内转换
   为 ASCII，支持整数、小数、指数、类型长度和 LIMIT。上标、圈号、罗马数字
   及零宽空格等不会被意外接受。符号、标点和未加引号的标识符语法不扩展。

3. SQL 字符串、反引号内数字和字符串形式的向量 JSON 不做空白/数字替换。
   VARCHAR 内容原样保留；例如引号内 JSON '[١,٢]' 仍按 JSON 规则拒绝。

实现位置

cpp/sql.cpp：Unicode 空白识别、数字 token 转换、标识符小写调用。
cpp/unicode.hpp：UTF-8 解码、属性查询及带上下文的小写转换，保留 ASCII 快速路径。
cpp/unicode_data.hpp：生成并检入的 Unicode 15.0 表，约 53 KB；构建和运行无需
联网或调用 Python。更新表时才使用 tools/generate_unicode_tables.py。
上游 DerivedCoreProperties.txt 固定版本及 SHA256 均写入生成器和生成文件。
Docker 与 CMake 安装同时包含 Unicode 数据许可证。
