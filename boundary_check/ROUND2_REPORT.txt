覆盖重点

* 错误投影、错误列、非法类型、错误维度、向量 ORDER BY，即使表为空、WHERE
  无匹配或 LIMIT 0 也返回错误；失败语句不改变已有行。
* 选择列表别名覆盖同名源列时的 ORDER BY；WHERE 仍使用源列；反引号转义；
  相同列重复投影；距离别名覆盖标量列；标量别名覆盖向量列。
* float32 最小次正规数、半 ULP、正负零、最大有限值与溢出临界点；17 维向量
  内混合约 2^-149 至 2^127 的值；距离并列按主键升序；升/降序、K=0/1/10/
  超过记录数/4097；有无过滤、有无索引和崩溃重启后均使用独立真值。
* 超过 32 个等值条件键，触发行号列表淘汰；打乱 AND 条件顺序；重复和矛盾
  条件；索引表与无索引表对照；主键与向量列位置反转；更新过滤列及向量、
  失败批量插入、ROLLBACK/COMMIT、删除全表后主键重用与索引维护。

新增差异 1：重复别名的解析路径不一致

最小复现文件：duplicate_alias_case.sql。
数据：id=1 的向量 [0,0]；id=2 的向量 [10,0]；id=3 的向量 [5,0]。

SELECT id,L2_DISTANCE(v,[0,0]) AS x,L2_DISTANCE(v,[10,0]) AS x
FROM t ORDER BY x LIMIT 1;

Python: rows=[[1,0.0,10.0]]
C++:    rows=[[2,10.0,0.0]]
创建向量索引前后均可复现。

原因：Python engine.py 的 aliases 字典保留最后一个同名别名，但 distance_expr
通过 next(...) 找第一个同名投影，向量缓存/索引选候选时可能使用不同表达式。
C++ query.cpp 的编译别名映射及排序统一使用最后一个同名表达式。
另两条探针在 LIMIT 0 时，一方接受而另一方拒绝：
  SELECT v AS x,n AS x FROM t ORDER BY x LIMIT 0;
  SELECT n AS x,v AS x FROM t ORDER BY x LIMIT 0;
这是实际迁移差异，但不能把旧版 Python 的结果自动当作正确答案。赛题未明确
歧义别名规则，当前证据不足以确定应该返回哪个表达式或直接拒绝歧义引用。

新增差异 2：两版本共有的 MySQL 兼容性差异

场景                             两版本实测                    MySQL 默认行为
SQL 字符串中的反斜杠 n/t/0         保留反斜杠及后续字符          解释为换行/制表/NUL
反斜杠转义单引号                  INSERT 语法错误               可插入单引号
# 行注释                         语法错误                      支持
-- 后无空白，例如 id=1--x          作为注释忽略 x                不是注释
版本条件注释 /*!80000 WHERE...*/   忽略其中 WHERE，返回更多记录   满足版本条件则执行内容
双引号/相邻/N/字符集前缀字符串      语法错误                      默认模式支持
省略 AS、单引号别名、ORDER BY 1     语法错误                      支持
LIMIT 1 OFFSET 1 / LIMIT 1,1       语法错误                      支持

把 n=7 更新为 n=7                 affected_rows=1               通常返回实际改变的 0 行

MySQL 转义依赖 NO_BACKSLASH_ESCAPES，双引号依赖 ANSI_QUOTES；UPDATE 行数还可能
受客户端 CLIENT_FOUND_ROWS 影响。此表按默认 SQL 模式及实际改变行数口径比较。
这些差异在曾通过正式测试的 Python 版本同样存在，不能单独解释 C++ 版本失分。
赛题要求的 Unicode 码点比较优先于 MySQL 默认排序规则，不应盲目补齐完整 MySQL。

确定性崩溃测试

使用 test-only LD_PRELOAD 小库，仅在目标调用前后写入一个测试标记并暂停。
控制程序确认标记、确认没有 SQL 成功响应，再 docker kill --signal KILL。
没有人工修改数据库文件，没有注入磁盘错误，没有模拟断电。
专用派生镜像只用于测试，保留原始数据库入口/程序；不要将此镜像提交比赛。
