# IK 前缀链表删除优化（v7）

基础版本为 seekdb-query-optimization 当前提交 d7ec83b2ba07bf0c636107d9538ab954d1614b4d。用户报告该分支约49/50分，但尚未确认报告对应的精确提交。本轮不修改原分支，也不修改官方基准及评分文件。

## 修改依据

CJK 和量词处理器遍历到失效前缀后，调用按值 erase，会从链表头再次查找；而当前节点迭代器已知。改用 erase(iterator)，单次删除由线性查找变为常数时间。删除前先推进迭代器，避免释放后读取节点链接。CJK 新前缀插入和单字 token 添加同时检查错误码，分配失败时返回错误并清理状态，不再静默丢词。字典匹配调用、顺序、分词规则均保留。

## 正确性

Ubuntu Release 编译通过，67项生产依赖链接原生测试通过。新增参考链表逐字符差分、交错词典所有者、短/长重叠前缀、真正释放并填毒的节点分配器、分配失败后复用用例。SQL 对比完整输出，不仅核对命中数量：TOKENIZE SMART/MAX_WORD/BENG、索引、MATCH分数及表达式消费者、DML、重建、长输入、其他共享分词器，输出均与基础版本一致，stderr为空。未运行ASan或全仓库测试。

## 性能结论

使用官方完整参数：20000行、批500、分词3000轮、查询200轮、3组、预热30、SKIP_LOAD=0。虚拟机4核4GB，与正式环境不同。第一组按三类等权计算综合耗时下降 **0.655%**，IK分词下降0.402%，幅度不足以证明稳定提分。第二轮候选完成，但原版对照在索引构建中异常停顿，重启后原版DDL恢复仍停顿，已停止该自建测试并保留现场，不将不完整报告用于收益计算。不能据此声称满分或预测赛事分数。

另试过归一化缓冲复用、上下文内联、CJK小数组：分别两组综合收益约 +0.234%/-0.870%、-0.550%/-6.220%、-0.684%/+0.917%，均未证明稳定收益，已撤回；最终代码仅包含链表删除与错误处理修改。

原始有效报告和正确性摘要见同目录 fts-evidence/2026-11-07-v7。建议继续保留高分分支，当前候选首先作为可审阅的局部改进，不建议仅凭0.655%的单组数据消耗提测次数。
