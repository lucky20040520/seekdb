## 负载与采集口径

每轮 10000 行、128 维、1000 次 exact 查询、K=10，500 次无过滤、500 次等值过滤；5 个标签各 2000 行，每批 100 行 BEGIN/INSERT/COMMIT。三轮数据种子 19017–19019、查询种子 29017–29019。版本按轮交替顺序运行，计分关闭 profiling 和强杀注入。

每个写入/查询阶段分别使用全新容器、空数据卷和独立父 cgroup；限制 2 CPU、2 GiB、128 PID、禁用 swap。查询 T 只统计 1000 次请求至完整响应；B/M 从启动开始，包含装载、建索引、一次无过滤预热及退出后的写回。独立外部采样器在进程退出后 syncfs，确认无 dirty/writeback、累计 I/O 连续三次稳定，再读取父 cgroup io.stat 和 memory.peak。全表重启核验在此后另一个容器执行。

所有查询与独立 Python math.fsum 暴力真值比较：ID、数量、过滤、距离、并列主键顺序均验证，两组 Recall@10 都为 1.0。真值缓存按完整输入 SHA256 区分。最终二进制版两种场景共验证 6000 次查询；含所有基线与阶段对照，共 30000 次查询。

Linux Docker Desktop / WSL2，cgroupfs v2，数据设备 8:48 已用数据卷 st_dev 核对。固定本地缓存策略为全新空卷、提前预热镜像可执行层，不清理宿主全局缓存；本地合成数据、缓存流程及硬件不等同官方环境。物理 I/O 的 rbytes 在本次轮次均为 0，B 主要是装载及提交产生的写入，不能据此推断冷盘读取性能。

## 计分

`f(x)=(base+epsilon)/(base+actual+2*epsilon)`；`E_phase=0.6*f(T)+0.2*f(B)+0.2*f(M)`；`E=(E_write+2*E_query)/3`。epsilon 分别为 1 ms、1 MiB、1 MiB。固定 Python 基线取该场景三轮各指标中位数；每个候选轮独立计算 E，最终取三轮 E 中位数并保留六位小数。表内六项指标中位数仅作展示，没有用不同轮次的最佳指标拼接计分。

无索引和有索引场景各自冻结同一 Python 镜像的三轮结果，分别计算，不能横向混用 E。缺失 I/O 或内存的普通 CI 诊断输出 null，不计 E。

## 存储实测与改动

向量本体为 5120000 字节，即 4.8828125 MiB。以下是测量结束时所有数据文件的实际逻辑大小，独立于物理 B：

| 场景/版本 | 数据文件数 | 数据文件总字节数（三轮中位数） |
|---|---:|---:|
| no_index/冻结 Python | 201 | 25547833 |
| no_index/最终二进制版 | 101 | 5568017 |
| with_index/冻结 Python | 301 | 30838694 |
| with_index/最终二进制版 | 201 | 10859115 |

1. 复用本仓库 C++ 分支的连续 float32 数组、等值行号列表、距离复用和按需投影。缓存按可见不可变段签名失效；数据与过滤列表共享 16 MiB 预算，过滤列表另限 1 MiB/32 项。
2. 小表即使存在磁盘索引也尝试有界连续数组；大表使用流式扫描或磁盘 Flat。过滤在 TopK 前执行，距离相同时按主键排序，保留 exact 路线。
3. 新 .mvb 不可变段保存类型化标量及 float32，段尾合并主键与行位置。目录缓冲超过 256 KiB 时落临时文件，最终并入单个持久化段；减少向量文本、侧文件和同步次数。段与必要索引落盘后仍原子发布清单并同步目录，随后才能成功响应。
4. 流式及外部排序的向量 TopK 只保存距离、主键和行位置；输出需要时才读取完整行，相同距离表达式直接复用。

C++ 支持旧 JSONL/Flat 文件和新旧混合段；旧 Python 不识别新的 .mvb 格式。两个实现始终用独立数据目录。本次覆盖单进程 SIGKILL 恢复，不把它等同断电或磁盘损坏测试。
