# 全文索引第五轮：短查询归并与无打分列输出

起点为 `9189661e292bd96416f9a607dab292df1b021bd6`（`codex/fts-tuning-v4`）。
用户提供的最新统一评测性能分为 **56.5926**，综合提升率 **28.2963%**。
以下只报告相对该版本的同机实测收益，不推算新正式分数。正式成绩需要 CI 复测。

## 瓶颈与实现

此前查询采样中，短词列表的 `ObSimpleRowsMerger`、数据移动和逐文档收集占有明显开销。
该合并器仅用于三路以内，push/top/pop/empty 等函数很短，但原热循环通过抽象接口
反复虚调用，限制内联。现在仅在对应短路数归并中使用具体类型访问适配器，复用同一份
fill/collect 模板，让编译器内联这些调用。超过三路仍使用原 loser tree；比较器、
相等项按迭代器序号排序、分值累加顺序、去重和结果过滤均保持原算法。
没有修改共享 `ObSimpleRowsMerger`，也没有按测试词或数据规模选择结果。

第四轮把是否需要 BM25 和是否需要内部相关度投影绑定在一起，返回 ID/普通列时
只能保留打分。本轮分离这两个条件：仅判定命中的自然语言查询可保留正数命中标记，
供回表所需的内部列布局使用，同时不初始化或执行 BM25。DAAT 与 TAAT 均区分
实际分值输入和投影，并保持 TAAT 的分区/去重处理。

优化仍限定单表、无子查询、无 boost，MATCH 只作为独立 WHERE 真值条件。
分值输出、数值阈值、相关度排序、布尔模式、JOIN 和无法证明安全的表达式保留打分。
允许普通字段投影和字段过滤，并显式排除非 MATCH 的其他检索函数。

**自然语言 LIMIT 会自动生成相关度排序**。执行计划确认即使外层只 COUNT，
内层 LIMIT 仍消费相关度；这里继续计算真实分值，保持入选文档语义。
没有为了加速 LIMIT 取消排序或按文档 ID 提前截断。

## 正确性验证

Release 增量构建成功。26 项生产依赖链接的原生 FTS 测试全部通过；新增归并用例覆盖
1–6 路、有跨路重复文档、负数 ID、空流、分值累加、匹配数量限制与 reuse，核对完整
文档序列及分值。既有二进制字符串比较、分词、字典及正规化测试保持通过。

扩展 SQL 差分回归覆盖返回 ID/正文/普通字段、回表过滤、LIMIT/OFFSET、二进制主键
（含 NUL）及复合主键；还保留分值投影、阈值、相关度排序、GROUP BY、OR、JOIN、
布尔模式、DML、空词/停用词/NULL/空表。参数化查询在短词与超过 256 词之间切换，
同时核对 COUNT 与返回列，覆盖 DAAT/TAAT 路径切换。
