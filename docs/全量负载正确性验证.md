# 完整负载的全量正确性核对

本轮从每轮30条查询抽查，扩展为每轮1000条查询全部计算独立真值；每轮10000条写入记录，在关闭前及重新打开后各核对一次完整内容。

## 独立性和核对范围

使用固定种子重新生成预期记录，独立转换为float32。数据库返回行须具有有效且不重复的主键，普通列和向量须与预期逐项相等，所有预期记录须出现。真值不能从数据库返回向量生成，否则错误写入可能同时污染答案和真值。

查询真值使用独立标量math.fsum计算欧氏距离，按距离、主键选Top10。带过滤查询先选满足等值条件的参考记录。比较完整ID序列和距离，因此错误数量、重复ID、错误过滤集合及并列顺序会失败。距离比较保留1e-12的本地交叉验证容差，不改动正式公开包的1e-5规则。

验证器故障注入：故意修改向量、遗漏记录、重复记录、错误距离、错误并列顺序及遗漏/重复查询结果均被拒绝。200行/8维/20查询的全量试跑已通过。

## 计时和资源边界

持久化内容核对及真值计算都在写入、查询计时之外。新增参考记录、分组和答案保留消耗测试工具内存，不是数据库性能优化，也不能用此同进程工具推断正式数据库容器的memory.peak。本轮不计算物理I/O、内存效率、综合E或排名。

三个工作进程使用同一固定数据生成方法，复用远程容器及OS页缓存，不宣称执行了官方冷缓存初始化。所有查询核对仍不能替代29例正式功能准入、官方协议或隐藏数据。
