## 广度优先的执行约束

先遍历所有必测类别，建立可执行最小闭环；每项均记录输入、预期、实际、版本及日志。未执行、失败、缺少官方约定分别标记，不能视为通过。公开通过、自建通过、正式通过分别报告。任一必测缺口存在时，暂停可选算法和外围格式增强。一次零分应重审全表；同一假设没有新增证据时不持续深化。

## 验收项目

下表是需求及测试设计，具体已执行结果见文末覆盖状态及《验证记录》；未运行的项目不计为通过。

| ID | 必测能力 | 最小正例与反例 | 交叉场景 |
|---|---|---|---|
| P01 | stdin/stdout 协议 | 就绪、语句边界、结果、错误、flush、退出 | 连续多语句、stderr 隔离；等待题包 |
| S01 | 表定义 | BIGINT 主键、VARCHAR(n)、VECTOR(n) | 重复表/列、非法维度、多个向量列、重启后 schema |
| S02 | 主键与整数 | 唯一主键、BIGINT 边界 | 多行后部重复、整数溢出，整条语句原子失败 |
| S03 | 字符串 | Unicode 字符长度与码点排序 | 中文、emoji、引号、边界长度、超长输入 |
| S04 | 向量校验 | 存储为 float32 后计算距离 | 维度不符、NaN、Infinity、转换溢出、舍入后并列 |
| Q01 | INSERT | 单行、多行 | 列顺序依正式语法；后部行失败无部分写入 |
| Q02 | SELECT | 投影、星号、五种比较、AND | 空表、空集、多条件、非法列、不支持语句返回错误 |
| Q03 | ORDER BY / LIMIT | 升降序按正式语法、数量限制 | 并列按主键升序、K 大于集合；LIMIT 边界待合同 |
| Q04 | UPDATE / DELETE | 主键及条件修改、删除 | 多行校验失败不能部分修改，禁止主键更新 |
| V01 | 精确 L2 TopK | 欧氏距离、按距离及主键排序 | WHERE 内算 TopK；全局近邻均不匹配的反例 |
| V02 | 空集和不足 K | 返回 0 到 min(K,N) 条 | 稀疏过滤、距离并列、删除后不足 K |
| V03 | exact 与 ann | 默认 exact、显式切换 | 建索引后 exact 仍须精确，模式入口等题包 |
| V04 | 索引维护 | 建索引后插入、更新、删除 | 事务内修改、回滚、重启重建、重复索引行为待合同 |
| T01 | 自动提交 | 成功语句持久化 | 响应成功后立即强杀，修改仍存在 |
| T02 | 显式事务 | BEGIN、COMMIT、ROLLBACK、读己之写 | 普通查询和向量查询可见性同步 |
| T03 | 语句原子性 | 失败语句无残留 | 事务内先成功、后失败，之前成功部分仍可提交 |
| T04 | 回滚一致性 | 行内容和集合均恢复 | 向量值更新、删除、插入、索引结果同步恢复 |
| D01 | 正常重启 | schema、行、向量持久化 | 关闭时未提交事务回滚 |
| D02 | 强杀恢复 | 已确认提交保留，未请求提交回滚 | 已请求未确认允许全有或全无，禁止部分生效 |
| D03 | 重复恢复 | 恢复中再次强杀后重启 | 幂等重放、残留尾记录、就绪前索引重建完成 |
| R01 | 有界内存 | 数据超过内存预算仍可处理 | 写入、排序、事务、恢复、索引准备均须受限 |
| R02 | 运行环境 | Linux x86_64、禁网、前台、全部文件 /data | 构建依赖锁定、CPU/磁盘/启动/查询超时等题包 |
| A01 | 学习材料 | agent/conversation.json，UTF-8 对象，≤128 KiB | 拒重复键、非标准数；学生/Agent/工具区分；无密钥 |
| A02 | 证据真实性 | 原始学生贡献与具体结果均内嵌 | 不冒写学生解释；计划不写成完成；同一链不拆分凑分 |
| C01 | 提交一致性 | 同 commit 源码、Dockerfile、JSON、说明 | HTTPS 仓库、指定分支、40 位 SHA；先预检再正式 |

## 必测完成后的性能阶段

先保留精确扫描基线，再比较候选索引。题面默认 10,000 行、128 维、1,000 查询、K=10，一半等值过滤；最终规模及限制以冻结题包为准。有过滤与无过滤两组 Recall@10 分别至少 0.95。三轮分别计算 E，取中位数，不能拼接最佳 T/B/M。I/O 和峰值内存包含装载、建索引、预热和页缓存；不能只看查询时间或进程 RSS。

## 需要组织方补齐的接口

SQL 语法及转义、输出及数值格式、错误码、就绪标识、模式切换、退出命令、故障注入驱动、公开输入及预期、依赖白名单、基础镜像、CPU/内存/磁盘/超时、最大数据/维度/K、索引是否为准入必测。未确定这些前不宣称兼容正式评测。
